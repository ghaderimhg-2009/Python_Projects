Python List Length

This project is a simple Python exercise for learning about Lists and the "len()" function.

The program creates a list containing several numbers and uses the "len()" function to calculate and display the number of elements in the list.

Topics Covered

- Creating a List in Python
- Working with list elements
- Using "len()" to count the number of elements
- Using "print()" to display the result

Project Goal

The goal of this exercise is to understand lists and learn how to find the number of elements in a list using Python.

Language: Python 🐍
