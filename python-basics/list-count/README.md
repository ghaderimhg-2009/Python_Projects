Python List Count

This project is a simple Python exercise for learning how to use the "count()" method with Lists.

The program creates a list of numbers and uses the "count()" method to find how many times a specific value appears in the list.

Topics Covered

- Creating a List in Python
- Working with list elements
- Using "count()" to count occurrences of a value
- Using "print()" to display the result

Project Goal

The goal of this exercise is to understand how to count the occurrences of a specific value in a Python list.

Language: Python 🐍
