Python String Methods

This project is a simple Python exercise for learning how to use basic string methods.

The program converts a string to lowercase using "lower()" and then separates the string into individual words using "split()".

Topics Covered

- Working with strings in Python
- Using "lower()" to convert text to lowercase
- Using "split()" to separate a string into words
- Converting a string into a list
- Using "print()" to display the result

Project Goal

The goal of this exercise is to become familiar with basic string methods and understand how to manipulate text in Python.

Language: Python 🐍
