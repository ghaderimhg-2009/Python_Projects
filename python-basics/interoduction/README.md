Python Personal Information

This project is a simple exercise for learning about variables and strings in Python.

In this program, information such as name, last name, age, and city is stored in variables and then displayed in an organized output using f-strings.

Topics Covered

- Defining variables in Python
- Working with string data
- Using "f-strings"
- Using "\n" to create new lines
- Displaying variable values with "print()"

Project Goal

The goal of this exercise is to become familiar with defining variables and displaying information in Python.

Language: Python 🐍
