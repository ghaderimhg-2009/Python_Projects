Python String Slicing

This project is a simple Python exercise for learning about Indexing and Slicing in strings.

In this program, the string "Python" is used to access and extract different parts of the string using indexing and slicing.

Topics Covered

- Working with strings in Python
- String Indexing
- String Slicing
- Accessing specific characters
- Extracting different parts of a string
- Using "f-strings"
- Using "\n" to display output on multiple lines

Project Goal

The goal of this exercise is to understand how to access characters and slice strings in Python.

Language: Python 🐍
