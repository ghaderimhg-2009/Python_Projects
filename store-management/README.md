Python Dictionary Operations

This project is a simple Python exercise for learning how to work with Dictionaries and perform different operations on them.

The program stores product names and prices in a Dictionary and performs several operations, such as updating a price, adding a new product, deleting a product, and displaying keys, values, and items.

Topics Covered

- Creating a Dictionary in Python
- Working with "key" and "value"
- Updating a value using "[]"
- Adding a new item to a Dictionary
- Using "del" to remove an item
- Using "keys()" to display keys
- Using "values()" to display values
- Using "items()" to display keys and values
- Using "f-strings" to format output

Project Goal

The goal of this exercise is to understand how to create, modify, add, delete, and access data in a Python Dictionary.

Language: Python 🐍
