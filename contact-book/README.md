Python Dictionary Update

This project is a simple Python exercise for learning how to work with Dictionaries and update their values.

The program creates a dictionary containing names and phone numbers. Then, the phone number associated with ""Hosein"" is updated with a new value.

Topics Covered

- Creating a Dictionary in Python
- Working with key-value pairs
- Accessing dictionary values
- Updating a value using a key
- Using "print()" to display the result

Project Goal

The goal of this exercise is to understand how to create dictionaries and update their values using keys in Python.

Language: Python 🐍
