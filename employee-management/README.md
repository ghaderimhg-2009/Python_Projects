Python Employee Profile

This project is a simple Python exercise for working with Dictionaries and creating an employee profile.

The program stores employee information such as name, age, job, and salary in a Dictionary. It then updates the salary, adds a phone number, removes the city, and displays the keys, values, and items. Finally, it presents the employee information in a formatted profile.

Topics Covered

- Creating and working with Dictionaries
- Working with "key" and "value"
- Updating Dictionary values
- Adding new items to a Dictionary
- Using "del" to remove an item
- Using "keys()", "values()", and "items()"
- Accessing Dictionary values using keys
- Using "f-strings" to format output
- Creating a formatted text profile

Project Goal

The goal of this exercise is to practice working with Dictionaries and learn how to manage, update, and display structured information in Python.

Language: Python 🐍
