Collatz Sequence in Python

This project is a simple Python exercise for learning about while loops, conditional statements, and mathematical operations.

The program takes an integer from the user and generates the Collatz sequence until the number reaches "1". If the number is even, it is divided by 2. If the number is odd, it is multiplied by 3 and then increased by 1.

Topics Covered

- Getting user input with "input()"
- Converting input to an integer using "int()"
- Using "while" loops
- Using "if" and "else" conditions
- Checking whether a number is even or odd using "%"
- Integer division using "//"
- Performing mathematical operations
- Using "print()" to display the sequence

Project Goal

The goal of this exercise is to practice "while" loops, conditional statements, and mathematical operations in Python while learning about the Collatz sequence.

Language: Python 🐍
