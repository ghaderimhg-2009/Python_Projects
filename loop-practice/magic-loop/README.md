Python Number Sequence

This project is a simple Python exercise for working with loops, conditions, and mathematical operations.

The program takes two integer inputs. It then repeats a process "n" times: if the number is even, it is divided by 2; otherwise, it is multiplied by 2 and decreased by 1. The result is printed after each step.

Topics Covered

- Using "input()" to receive user input
- Converting input to integers with "int()"
- Using "for" loops
- Using "if" and "else" conditions
- Checking even numbers with "%"
- Integer division using "//"
- Performing mathematical operations
- Using "print()" to display results

Project Goal

The goal of this exercise is to practice loops, conditional statements, and mathematical operations in Python.

Language: Python 🐍
