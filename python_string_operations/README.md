Python String Operations

This project is a simple Python exercise for learning how to work with strings and perform different operations on them.

The program demonstrates how to access specific characters, slice strings, reverse a string, and convert text to uppercase and lowercase.

Topics Covered

- Working with strings in Python
- String indexing
- String slicing
- Reversing a string
- Using "upper()" to convert text to uppercase
- Using "lower()" to convert text to lowercase
- Using "f-strings" to format output

Project Goal

The goal of this exercise is to become familiar with basic string operations and understand how Python handles strings.

Language: Python 🐍
