Python Shopping List

This project is a simple Python exercise for learning how to work with Lists and modify their elements.

The program creates a shopping list, removes an item using "remove()", adds a new item using "append()", and then removes the last item using "pop()".

Topics Covered

- Creating a List in Python
- Using "remove()" to remove a specific item
- Using "append()" to add a new item
- Using "pop()" to remove the last item
- Using "len()" to count the number of items
- Using "print()" to display the result

Project Goal

The goal of this exercise is to understand how to add, remove, and count items in a Python list.

Language: Python 🐍
